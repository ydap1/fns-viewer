# Просмотрщик налоговой XML-базы

Локальный поиск и просмотр `data.xml` в браузере. 

## Установка

Нужен [Git](https://git-scm.com) и 64-разрядный Python 3 (на Windows отметьте
**Add Python to PATH**). Скачивать архивом не нужно — такая копия не обновляется.

```sh
git clone https://github.com/ydap1/fns-viewer.git
cd fns-viewer
```

Положите в эту папку `data.xml` (~3,4 ГБ): в репозиторий база не входит из-за
размера, имя и расположение фиксированные.

## Запуск

| Linux и macOS | Windows |
| --- | --- |
| `./linux_launch.sh` в терминале | двойной щелчок по `launch.bat` |

Скрипт делает `git pull` и открывает <http://127.0.0.1:8765>. Первый запуск
строит индекс (~477 МБ, полминуты), дальше мгновенно.

## Статистика начислений (форма 5-МН)

В карточке документа под ставками и льготами показывается, что по этим налогам
реально начислено: число плательщиков, налоговая база, сумма налога и сумма
выпавших льгот. Загрузить или обновить:

```sh
pip install -r requirements.txt      # нужно только для файлов 2012-2014 годов
python3 viewer.py --update-stats
```

Пара минут, 14 лет данных в `tax_viewer_stats.sqlite3`. Без этого шага
просмотрщик работает как раньше, просто без раздела статистики.

Форма 5-МН публикуется **по субъектам РФ, не по муниципалитетам**, поэтому в
карточке муниципального документа стоят цифры по региону целиком — об этом там
же написано.
