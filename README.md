# Просмотрщик налоговой XML-базы

Программа позволяет искать и просматривать `data.xml` локально: данные никуда
не отправляются и не изменяются.

## Что нужно перед запуском

В той же папке, где лежит `viewer.py`, должен быть файл `data.xml` — сама база
(около 3,4 ГБ). Имя и расположение фиксированные: программа ищет именно
`data.xml` рядом с собой. В репозиторий он не входит из-за размера, скачайте его
отдельно и положите в папку. Рядом также должен лежать
`structure-20140602.csv` — описание полей; он уже есть в репозитории.

## Что видно в открытом документе

- **Категория плательщика.** Кнопки «Все категории / Физические лица /
  Юридические лица / Индивидуальные предприниматели» оставляют в документе
  только те ставки и льготы, которые относятся к выбранной категории. На каждой
  кнопке сразу видно, сколько ставок и льгот для неё есть. Если в документе
  признаки ФЛ/ЮЛ/ИП не заполнены (так бывает, например, у налога на имущество
  организаций), выбирайте «Все категории».
- **Ранжирование ставок.** Ставки больше не идут в перемешку: они собраны в
  группы по объекту налогообложения (у заголовка группы показано число ставок и
  разброс ставки). Внутри группы строки идут по возрастанию ставки. Список
  «Ранжировать» переключает порядок: по объекту налогообложения, по ставке по
  возрастанию или по убыванию. Льготы так же можно ранжировать по категории
  налогоплательщика, по размеру льготы или по статье документа.
- **Выгрузка одного документа.** Кнопка «Скачать этот документ в Excel»
  выгружает только открытый документ и учитывает выбранную категорию
  плательщика. В выгрузке ставки уже отсортированы, добавлены столбцы «Группа
  объекта налогообложения» и «Уточнение объекта», а ставки и размеры льгот
  записаны числами — по ним можно сортировать и считать прямо в Excel.

Кнопка «Скачать Excel (до 1000 записей)» под таблицей поиска выгружает
результаты поиска целиком, ставки в ней отсортированы так же.

## Запуск на macOS или Linux

```sh
python3 viewer.py --open-browser
```

После запуска откроется <http://127.0.0.1:8765>.

## Как передать другу с Windows

Передайте ему всю папку с этими файлами:

- `data.xml` — сама база (3,4 ГБ);
- `structure-20140602.csv` — описание полей;
- `viewer.py`;
- `Запустить_просмотрщик_Windows.bat`.

Другу достаточно дважды щёлкнуть `Запустить_просмотрщик_Windows.bat`. Если на
компьютере ещё нет Python, скрипт подскажет установить 64-разрядный Python 3 с
python.org. Во время установки Python нужно поставить галочку **Add Python to
PATH**. Никакие дополнительные пакеты или доступ к интернету после этого не
нужны.

При первом запуске создаётся `tax_viewer_index.sqlite3`: локальный индекс для
поиска. На этой базе он занимает около 664 МБ, зато последующие запуски быстрые.
Его можно тоже передать вместе с папкой, чтобы другу не ждать построения
индекса; если не передавать, он будет создан автоматически. После замены
`data.xml` индекс также будет перестроен автоматически. Чтобы принудительно
построить его заново, используйте:

```sh
python3 viewer.py --rebuild
```
