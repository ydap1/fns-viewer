# Просмотрщик налоговой XML-базы

Локальный поиск и просмотр `data.xml` в браузере. Данные никуда не отправляются
и не изменяются.

## Установка

Нужен [Git](https://git-scm.com) и 64-разрядный Python 3 (на Windows при
установке отметьте **Add Python to PATH**).

```sh
git clone https://github.com/ydap1/fns-viewer.git
cd fns-viewer
```

Положите `data.xml` (~3,4 ГБ) в эту папку. База в репозиторий не входит из-за
размера, её нужно получить отдельно; имя и расположение фиксированные.

## Запуск

```sh
./launch.sh          # macOS, Linux
launch.bat           # Windows: двойной щелчок
```

Скрипт сам делает `git pull`, поэтому обновления приезжают при каждом запуске, и
открывает <http://127.0.0.1:8765>. Текущая версия видна в шапке страницы.

Без обновления: `python3 viewer.py --open-browser`.

Скачивать репозиторий архивом (ZIP) не нужно: такая копия не обновляется, и
скрипт запуска об этом предупредит.

При первом запуске строится индекс `tax_viewer_index.sqlite3` (~477 МБ, около
30 секунд), дальше запуск мгновенный. Пересобрать вручную:
`python3 viewer.py --rebuild`.

## Поиск

Строка поиска ищет по началу слова в названии муниципального образования, в
названии документа и в коде ИФНС: `моск` находит «Москва», `оскв` — нет.
Фильтры, сортировка и страница попадают в адрес — ссылку на результат поиска
можно сохранить.
