# Просмотрщик налоговой XML-базы

Локальный поиск и просмотр `data.xml` в браузере. Данные никуда не отправляются
и не изменяются.

## Запуск

Положите `data.xml` (~3,4 ГБ) в папку рядом с `viewer.py` — путь фиксированный, в
репозиторий файл не входит из-за размера.

```sh
python3 viewer.py --open-browser
```

Откроется <http://127.0.0.1:8765>. На Windows — двойной щелчок по `launch.bat`,
нужен только 64-разрядный Python 3 с галочкой **Add Python to PATH**.

При первом запуске строится индекс `tax_viewer_index.sqlite3` (~477 МБ, около
30 секунд), дальше запуск мгновенный. Пересобрать вручную:
`python3 viewer.py --rebuild`.

## Поиск

Строка поиска ищет по началу слова в названии муниципального образования, в
названии документа и в коде ИФНС: `моск` находит «Москва», `оскв` — нет.
Фильтры, сортировка и страница попадают в адрес — ссылку на результат поиска
можно сохранить.
