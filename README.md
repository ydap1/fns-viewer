# Просмотрщик налоговой XML-базы

Локальный поиск и просмотр `data.xml` в браузере. 

## Установка

Нужен [Git](https://git-scm.com) и 64-разрядный Python 3 (на Windows отметьте
**Add Python to PATH**). Скачивать архивом не нужно — такая копия не обновляется.

```sh
git clone https://github.com/ydap1/fns-viewer.git
cd fns-viewer
```

Положите в эту папку `data.xml` (~3,4 ГБ): в репозиторий база не входит из-за
размера, имя и расположение фиксированные.

## Запуск

| Linux и macOS | Windows |
| --- | --- |
| `./launch.sh` в терминале | двойной щелчок по `launch.bat` |

Скрипт делает `git pull` и открывает <http://127.0.0.1:8765>. Первый запуск
строит индекс (~477 МБ, полминуты), дальше мгновенно.
